# Sound credits

All pet sounds in this folder are edited excerpts of real animal recordings from [Freesound](https://freesound.org),
each released by its author under **Creative Commons 0 (CC0 1.0, public domain dedication)**:
https://creativecommons.org/publicdomain/zero/1.0/ . No attribution is legally required; it is recorded here as a courtesy
and so each file can be traced back to its source. The license was checked on every source sound's own Freesound page.

Edits: trimmed to a single event (or a short sequence / seamless loop), high-pass filtered, mixed to mono, loudness-normalized
(about -16 LUFS, peak <= -1 dBFS), encoded as AAC .m4a (mono, 44.1 kHz, 64 kbps; the purr and panting loops 96 kbps). Source = the Freesound HQ preview.
